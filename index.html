JT — Job Announcement Pipeline

Ingest→Detect→Parse→Draft
Processing pipeline · Concept diagram

A Python pipeline that processes job-announcement posts, extracts structured details and prepares concise drafts for X.

Python · Streamlit · Google Gemini · Playwright · Pydantic
Repository ↗
Project case study

Problem and approach

Job announcements often contain unstructured details. JT separates collection, detection, parsing and draft generation into a repeatable workflow.

Implementation

  • Accepts JSON and CSV inputs, with optional URL/search collection.
  • Uses Gemini for classification and extraction, with heuristic fallbacks.
  • Offers both a command-line interface and a Streamlit interface.
  • Prepares X-ready drafts; publishing is opt-in and defaults to off.

Responsible use

Customer Churn Prediction

Clean data→Encode→Train→Predict
Machine-learning workflow · Concept diagram

A telecom churn analysis and classification workflow that estimates churn likelihood for customer records.

Python · Pandas · NumPy · scikit-learn · Matplotlib
Repository ↗
Project case study

Problem and approach

The project explores how customer attributes relate to churn and builds classification models to estimate churn likelihood.

Implementation

  • Exploratory analysis and data cleaning, including conversion of TotalCharges to numeric.
  • One-hot encoding and a stratified train/test split.
  • Trains Logistic Regression and Random Forest classifiers.
  • Reports classification metrics and ROC-AUC; prediction code produces churn probabilities for new records.

Evaluation note

Actual performance depends on the dataset and should be generated by running the training workflow. No benchmark score is claimed here.
