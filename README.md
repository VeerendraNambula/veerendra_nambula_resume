# Veerendra Nambula — Portfolio & Resume

A responsive personal portfolio built with semantic HTML, CSS and structured metadata. Hosted on GitHub Pages.

- **Live portfolio:** https://veerendranambula.github.io/veerendra_nambula_resume/
- **Resume:** [View or download PDF](veerendra_nambula_resume.pdf)
- **GitHub profile:** [VeerendraNambula](https://github.com/VeerendraNambula)
- **LinkedIn:** [Connect](https://www.linkedin.com/in/veerendra-nambula)

## What's included

- Responsive desktop and mobile layout.
- Project cards with expandable case studies and source repository links.
- Experience, education and categorized technical skills.
- SEO metadata, canonical URL, social-sharing metadata and Person structured data.
- Custom SVG favicon, sitemap and robots.txt.
- Accessible skip link, visible keyboard focus and reduced-motion support.

## Local preview

Open `index.html` in a browser, or run a local server from the repository root:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

GitHub Pages deploys the static site through the workflow in `.github/workflows/pages.yml`.

The resume PDF remains the original uploaded file; it has not been regenerated or modified by the website build.
